# Tungsten Edge 钨极 v0.7.7

这一版主要解决一件事：**进全屏时任务条会闪一下**——现在四种进全屏的方式都不闪了。另外有两处升级后你会直接注意到的变化（拖进抽屉的应用会自动被保留、设置页少了一组），写在最前面。还有外观手动挡、空抽屉提示，以及避让功能开着时更省电。

版本号是小版本，但**确实有行为变化**，请先看前两节。

## ⚠️ 拖进抽屉的应用会自动勾上「在程序坞中保留」

以前「位置」和「保留」是两件独立的事，结果一个普通应用拖进抽屉后，**一退出就从抽屉里消失了**——因为抽屉的显示规则是「正在运行 或 已勾保留」。这跟「我把它收进抽屉 = 我要它一直在那儿」明显不符。

现在拖进抽屉就自动帮你勾上保留。两点说清楚：

- **只管进不管出**：拖回任务条不会取消勾选。不想保留的，右键取消勾选即可。
- **每次拖进去都会重新勾上**，包括你手动取消过之后又拖进去一次。这是有意的。

## ⚠️ 设置页里的「系统 Dock」那一组删掉了

那一组原本只有一句指路文字和一个按钮，而那个按钮和菜单栏菜单里的完全重复。现在**系统 Dock 的入口只在菜单栏图标的菜单里**（点菜单栏的钨极图标，里面有系统 Dock 的唤醒延迟滑杆和「打开系统 Dock 设置…」）。

顺带也删掉了设置页「任务条」组末尾那句指路文案。

## 进全屏不再闪烁

以前切进全屏的那一瞬间，任务条会被系统的转场动画抓进画面、闪一帧。这一版四种进全屏的方式都不闪了：窗口绿灯、`Control-Command-F`、`Control-左右方向键`、三指水平滑动。

默认开启；不需要的话在「设置 → 高级」里关掉「预测全屏切换，消除任务条闪烁」。

一个已知的代价：**用三指往全屏空间的方向滑、滑到一半又收回来**，任务条会短暂消失一下再回来。我们认为这比每次进全屏都闪一下更值。

## 新增：可以手动选浅色 / 深色

**设置 → 通用 → 外观**：跟随系统 / 浅色 / 深色，默认跟随系统，作用于整个应用。以前只能跟着系统走，现在系统是浅色你也可以让钨极保持深色，反过来也行。

## 新增：空抽屉会告诉你该怎么用

抽屉两个区都空着的时候，以前渲染成一个约 24×24 的空毛玻璃小方块——看不懂是什么，也很难当成拖放目标。现在会显示「将应用拖入抽屉区」，并且按满行宽度撑开，所以你拖进第一个应用时面板宽度不会跳一下。

## 修复：相邻全屏应用互相切换时，任务条不再脉冲一下

两个全屏应用之间来回切的时候，任务条会极短地闪现（实测约 2–11 毫秒的脉冲）。原因是切换那一刻系统给出的窗口信息是过渡状态，钨极信了它、于是短暂地把自己显示出来。现在改成切换后再确认一次，过渡期间保持隐藏。

## 优化：勾了「最大化窗口避开任务条」时更省电

这个功能原本每秒扫描全屏窗口 5 次，**不管有没有事发生**。现在改成由窗口的移动 / 缩放 / 创建 / 前后台切换这些事件驱动，加上 1 秒一次的兜底。

实测（开着避让、真空闲状态）：整体空闲 CPU 从 `0.970%` 降到 `0.691%`（−29%），其中避让本身的开销从 `0.42` 个百分点降到 `0.12` 个百分点（−73%）。

**抬升的手感不变**：一旦有窗口正在被托举或还原，立刻回到原来的高频检测；前台切换、焦点切换、新窗口出现都会立即扫描，不会出现「要等兜底才抬起来」。

## 安装

下载 `Tungsten-Edge-0.7.7.dmg`，拖进「应用程序」即可。

或用 Homebrew：

```
brew install --cask moonbai-studio/tungsten-edge/tungsten-edge
```

**首次打开**：这个包没有 Apple 开发者签名，macOS 会拦一下。右键点图标选「打开」，或到「系统设置 → 隐私与安全性」里点「仍要打开」。

**需要辅助功能权限**：任务条要读取和操作窗口，第一次启动会引导你去授权。
