## Drag apps straight into the drawer

Drag an app from Finder, or from the Apps popup on the taskbar, onto the drawer icon at the right end of the taskbar and let go: it goes to the front of the drawer. Pause over the icon and the drawer opens, so the app can be dropped exactly where it should go.

## New and improved

- Apps dragged from the taskbar onto the drawer icon also go to the front of the drawer.
- When an app is dragged from Finder onto the taskbar, the other icons now make room immediately.

## Fixed

- The taskbar kept showing windows that some apps, such as Bilibili, had closed.
- An app dragged from Finder onto the taskbar did not appear there when it was already in the drawer.
- The drawer icon shifted as the taskbar resized while an item was dragged onto it.

## Installing

**Already on 0.9.0 or later?** Do nothing — the update will find you, or use *Check for Updates…* in **Settings → About**. Your Accessibility permission carries over.

**New install:** grab the `.dmg` from the [official website](https://tungstenedge.app) and drag it into Applications, or:

```bash
brew install --cask tungsten-edge
```

Requires macOS 12 or newer. Universal — Apple silicon and Intel.

## 把应用直接拖进抽屉

从访达，或从 Dock 栏上的「应用程序」弹窗，把应用拖到 Dock 栏右侧的抽屉图标上，松手即放进抽屉最前面；在图标上稍作停留，抽屉会展开，可直接放到想要的位置。

## 新增与改进

- 从 Dock 栏拖到抽屉图标上的应用同样排在抽屉最前面。
- 从访达把应用拖到 Dock 栏时，其他图标立即让出位置。

## 修复

- 部分应用（如哔哩哔哩）关闭窗口后，窗口卡仍留在 Dock 栏上。
- 从访达拖到 Dock 栏的应用若已在抽屉中，不会出现在 Dock 栏上。
- 把卡拖向抽屉图标时，Dock 栏伸缩导致抽屉图标移位。

## 安装

**已经装了 0.9.0 或更新的版本？** 什么都不用做——更新会自己找上门，也可以在「设置 → 关于」里点「检查更新…」。辅助功能授权不用重新给。

**新装：** 到[官网](https://tungstenedge.app)下 `.dmg` 拖进「应用程序」，或者：

```bash
brew install --cask tungsten-edge
```

需要 macOS 12 或更新版本。通用架构——Apple 芯片与 Intel 都可以。
