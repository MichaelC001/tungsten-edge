## Pinned folders can now fan out

Right-click a pinned folder on the taskbar and choose Fan, Grid or List under *View content as*. The default, Automatic, fans the folder out when it holds a few items and switches to a grid when it holds more.

## New and improved

- Pinned folders can now also be sorted by Date Created.
- Improved the opening and closing animations of folder and Trash popups.
- The interface is now available in Russian, Turkish, Hindi and Vietnamese.
- Improved the menu bar icon.

## Fixed

- Liquid Glass on the taskbar looked milky white on some Macs running macOS 26.
- Automatic update checks stopped after an update alert was dismissed once.

## Installing

**Already on 0.9.0 or later?** Do nothing — the update will find you, or use *Check for Updates…* in **Settings → About**. Your Accessibility permission carries over.

**New install:** grab the `.dmg` from the [official website](https://tungstenedge.app) and drag it into Applications, or:

```bash
brew install --cask tungsten-edge
```

Requires macOS 12 or newer. Universal — Apple silicon and Intel.

## 固定的文件夹，可以扇状展开了

右键 Dock 栏上的固定文件夹，在「显示内容为」中可选扇状、网格或列表；默认「自动」，文件少时以扇状展开，较多时改用网格。

## 新增与改进

- 固定文件夹的「排序方式」新增「创建日期」。
- 优化文件夹与废纸篓弹窗的打开、收起动画。
- 界面新增俄语、土耳其语、印地语、越南语。
- 优化菜单栏图标。

## 修复

- 部分 macOS 26 机器上 Dock 栏液态玻璃显示为乳白色。
- 关闭一次更新提示后，不再自动检查新版本。

## 安装

**已经装了 0.9.0 或更新的版本？** 什么都不用做——更新会自己找上门，也可以在「设置 → 关于」里点「检查更新…」。辅助功能授权不用重新给。

**新装：** 到[官网](https://tungstenedge.app)下 `.dmg` 拖进「应用程序」，或者：

```bash
brew install --cask tungsten-edge
```

需要 macOS 12 或更新版本。通用架构——Apple 芯片与 Intel 都可以。
